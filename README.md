# 🍼 奶爸成长笔记

> 写给 18 岁的你：这是爸爸陪你长大的第 N 年。这里没有完美的爸爸，只有一个每天努力变好一点的人。

## 这是什么

一个爸爸的自我成长记录体系。每天一条记录，坚持 18 年，等儿子 18 岁时作为礼物送给他。

**核心玩法：** 每晚 21:00 机器人自动开当日 Issue → 手机上回复一条（哪怕一行）→ 机器人自动 commit，格子变绿。30 秒完成记录。

## 每日记录格式

文件：`daily/YYYY-MM-DD.md`

```markdown
---
date: 2026-09-12
tags: [陪玩]        # 可选：健身/读书/学习/副业/陪玩（自由增删）
mood: 4             # 可选 1-5
---
## 今天做成的一件事
...

## 学到的东西
...

## 和宝宝的时刻 👶
...

## 想对18岁的你说    （可选，偶尔写）
...

## 随便聊聊          （自由区，想写多少写多少）
...
```

**所有字段可选**：累到只剩 30 秒的日子，写一行"今天太累了，但陪宝宝玩了积木"也算满勤。

## 坚持规则（宽松 streak）

- ✅ 一行也算记录（通过 Issue 回复即自动 commit）
- ✅ 可以**补票**：漏了 1~2 天，事后补写，streak 不断
- ❌ 连续漏 3 天，streak 才真正断
- 🌱 断了也不放弃——周报会温和地拉你回来，重新开始就是新的成长

## AI 反馈

| 频率 | 内容 | 口吻 |
|---|---|---|
| 每日 | 当日 Issue 里附一句话点评昨天 | 简短 |
| 每周日 | 《本周成长点评》：标签统计 + 肯定 + 温和追问 | 挚友型 |
| 儿子生日 | 年度长文《爸爸这一年》 | "18 年后的你"写信回来 |

## 隐私纪律 ⚠️

见 [PRIVACY.md](PRIVACY.md)。系统会自动检测并打码手机号/身份证号等，并在周报中做语义级隐私提醒。**请你写入前自查：不写儿子的正脸照片、住址、幼儿园/学校名称、真实全名。**

## 目录结构

```
daily/            每日记录（每年一个子目录归档）
reviews/weekly/   每周成长点评
reviews/annual/   年度报告
scripts/          机器人脚本
.github/          工作流
```

## 配置 Secrets（部署时设置一次）

| Secret | 用途 |
|---|---|
| `GLM_API_KEY` | 智谱 GLM API（bigmodel.cn 注册即送额度） |
| `SERVERCHAN_SENDKEY` | Server酱 SendKey（sct.ftqq.com，微信扫码登录获取；每晚提醒直达个人微信） |

## 开始

```bash
# 手动记录（不通过 Issue 时）
cp daily/_TEMPLATE.md daily/$(date +%F).md
# 编辑后 commit & push，同样算打卡
```
